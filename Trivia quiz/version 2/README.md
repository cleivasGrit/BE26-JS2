# Trivia Quiz

Det här är en inlämningsuppgift i kursen JavaScript på Frontend-programmet vid Grit Academy. Uppgiften är att skapa ett Trivia-spel med hjälp av Open Trivia Database.

I spelet väljer spelaren först vilken typ av frågor hen vill ha samt hur många. Frågorna kommer sedan upp en i taget. För varje fråga får spelaren veta om hen svarade rätt eller fel. När alla frågor har visats får spelaren veta hur många av frågorna hen svarade rätt på.

## Kodstruktur

- `main.js` startar applikationen och kopplar formulären till rätt funktioner.
- `modules/triviaAPI.js` hämtar frågor från Open Trivia Database.
- `modules/gameplay.js` hanterar spelets regler, poäng och aktuell fråga.
- `modules/display.js` hanterar det som visas på sidan.

## Resurser

- Underscore: https://underscorejs.org/
- Open Trivia Database: https://opentdb.com/
